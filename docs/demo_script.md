# 1 分钟演示视频脚本

2026-09-06新版建议：提前启动chat.py并配置实际模型，准备1.pdf、2.pdf。0～10秒介绍Agent/Skill/pypdf；10～25秒输入“将1.pdf第2到3页提取出来”并展示预览，回复确认；25～40秒打开结果核对页数，输入“把它第1页旋转90度”并确认；40～55秒打开旋转结果，展示状态及调用次数；55～60秒说明不发送PDF正文、所有写入需确认。真实模型未配置前只能录制明确标注的规则演示，不得称为模型验收。以下保留旧单次接口演示供技术参考。

## 演示准备

在项目根目录打开终端，准备一个 5 页的 `report.pdf`。提前安装 `requirements.txt`。终端字号调大，确保 JSON 可辨认。

| 时间 | 画面/操作 | 旁白 |
|---|---|---|
| 0-6 秒 | 展示项目目录和架构图 | “这是 AI PDF 页面编排项目。它采用 Agent、Skill、CLI、pypdf 的轻量链路。” |
| 6-16 秒 | 打开 `SKILL.md`，快速扫过五类操作与 JSON 契约 | “Skill 定义提取、删除、合并、重排和旋转，并要求标准输出只有结构化 JSON。” |
| 16-28 秒 | 执行 `python agent/agent_entry.py --allowed-dir . --request "把 report.pdf 的第2到4页单独提取出来"` | “自然语言先被解析成操作计划。此时只预览，还没有写文件。” |
| 28-39 秒 | 指向 `confirmation_required` 和计划文字；复制令牌执行 `python agent/agent_entry.py --confirm "令牌"` | “用户确认后，一次性令牌触发 Skill，底层只使用 pypdf，并保留原文件。” |
| 39-47 秒 | 展示成功 JSON 和新生成的 `report_extract.pdf`，打开属性显示 3 页 | “结果精简返回处理页码、输出路径和页数，新文件包含第 2 到 4 页。” |
| 47-55 秒 | 执行非法示例：提取第 99 页 | “越界、损坏、加密和目录逃逸都会返回明确错误码，不产生半成品。” |
| 55-60 秒 | 展示 `python tests/run_tests.py` 的 `16/16` 汇总 | “自动化测试覆盖功能、边界、安全和完整确认链路，当前 16 项全部通过。” |

## 录制注意事项

- 令牌只展示本机临时值，录制后即失效；不要展示真实私人路径或文档内容。
- 若一分钟较紧，可提前准备命令并用上方向键调出。
- 最后一屏停留在测试汇总，便于验收人员看清结果。
